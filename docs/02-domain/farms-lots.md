# Fundos, parcelas/lotes y areas cultivables

## Modelo objetivo

- `farm`: fundo.
- `parcel` o `lot`: unidad fisica.
- `cultivable_area`: unidad productiva por campana, cultivo y variedad.
- `campaign`: periodo agricola.
- `crop` y `variety`: catalogos agricolas.

La etiqueta visible lote/parcela puede configurarse por cliente.
