# Identidad y acceso

## Principios

- Correo unico global.
- Roles por organizacion.
- Permisos por accion con claves estables.
- Alcances por organizacion, fundo, parcela canonica (`parcel`), area cultivable o recurso asignado.
- La API es la autoridad final.

## Permisos

Formato recomendado: `recurso.accion`.

Ejemplos: `parcels.read`, `parcels.geometry.update`, `satellite.ndvi.process`, `audit.read`.
