# Vision del producto

Construir una plataforma web SaaS multiempresa para administrar informacion agricola a nivel de parcela/lote, representar areas mediante poligonos geograficos, consultar imagenes satelitales, procesar indices de vegetacion y centralizar datos agronomicos, productivos y operativos.

La experiencia debe sentirse como una sola plataforma, aunque internamente existan aplicacion web, API, worker geoespacial, base de datos, cola y almacenamiento de objetos.
