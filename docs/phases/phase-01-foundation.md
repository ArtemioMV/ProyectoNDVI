# Fase 1: Fundacion tecnica

## Objetivo

Construir la base ejecutable del proyecto antes de implementar el nucleo funcional.

## Entregables iniciales

- Monorepo con `apps`, `packages`, `docs`, `skills` e `infrastructure`.
- Frontend React/Vite.
- Backend NestJS.
- Prisma configurado.
- Docker Compose con Nginx, PostgreSQL y Redis.
- Variables de entorno base.
- Documentacion inicial.

## Criterio de salida

El sistema debe levantar con Docker y exponer frontend, API y health check desde Nginx.
