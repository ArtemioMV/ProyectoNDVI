# ADR-010: Ubicacion de Tailwind

- Estado: Aprobado inicial
- Fecha: 2026-07-03

## Decision

Tailwind, PostCSS, `components.json` y estilos globales viven en `apps/web`.

## Consecuencia

No se colocan estos archivos en la raiz del monorepo salvo ADR futuro que justifique una configuracion compartida.
