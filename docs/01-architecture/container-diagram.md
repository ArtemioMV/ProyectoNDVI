# Diagrama de contenedores

## Contenedores principales

- Web: interfaz Next.js.
- API: NestJS, autorizacion, dominio, auditoria e integracion interna.
- Geo Worker: Python, raster/vector, indices y estadisticas.
- PostgreSQL/PostGIS: datos relacionales y espaciales.
- Redis: cola y estados transitorios.
- MinIO/S3: archivos raster, previews y objetos grandes.
- Nginx: unica entrada publica.
