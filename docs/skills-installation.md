# Instalacion y gestion de skills

La carpeta `skills/` contiene skills locales del proyecto. Tambien se pueden descargar skills externas desde Git cuando aporten mejores practicas especificas.

## Reglas para descargar skills desde Git

1. Usar repositorios confiables y revisar licencia.
2. Preferir skills pequenas y especificas.
3. Fijar version por tag o commit.
4. Leer el `SKILL.md` completo antes de usarlo.
5. Adaptar la skill al contexto del proyecto, no copiar reglas incompatibles.
6. No instalar skills que pidan secretos, credenciales o acceso amplio sin revision.
7. Registrar en este documento la fuente, version y motivo de adopcion.

## Skills recomendadas por area

- Frontend: Next.js, React, TypeScript, accesibilidad, formularios, tablas y mapas.
- Backend: NestJS, autorizacion, multi-tenancy, API REST, Prisma/PostGIS y auditoria.
- Geo: GDAL/rasterio, shapely, pyproj, procesamiento raster, estadisticas zonales y validacion geometrica.
- DevOps: Docker, Nginx, CI/CD, backups, secretos y observabilidad.
- Testing: unit, integration, E2E, fixtures geoespaciales y pruebas de seguridad multiempresa.
- Review: seguridad, tenancy, arquitectura y calidad.
