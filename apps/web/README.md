# Web

Aplicacion Next.js de la plataforma.

## Reglas

- Tailwind, PostCSS, `components.json` y `globals.css` pertenecen a esta carpeta.
- No conectar directamente a PostgreSQL, Redis ni MinIO.
- Consumir la API principal mediante clientes tipados.
- Reflejar permisos en UI, pero la API sigue siendo la autoridad.
