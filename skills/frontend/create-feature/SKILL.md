# Crear feature frontend

## Antes de modificar

- Leer `docs/05-frontend/architecture.md`.
- Leer el modulo relacionado en `docs/02-domain`.

## Reglas

- Crear la feature dentro de `apps/web/src/features`.
- Separar componentes, cliente API, tipos y helpers locales.
- No duplicar componentes de `src/components`.
- Cubrir estados de carga, error, vacio y sin permiso.
