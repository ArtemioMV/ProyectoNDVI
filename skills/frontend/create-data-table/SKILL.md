# Crear tabla de datos

## Antes de modificar

- Leer `docs/06-design-system/components.md`.
- Leer `docs/04-api/pagination.md`.

## Reglas

- Soportar carga, vacio, error y paginacion.
- Mantener orden estable.
- No cargar todos los datos si el endpoint debe paginar.
- Reflejar permisos de acciones por fila sin asumir seguridad final.
