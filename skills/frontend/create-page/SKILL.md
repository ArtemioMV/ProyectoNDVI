# Crear pagina frontend

## Antes de modificar

- Leer `docs/05-frontend/architecture.md`.
- Leer `docs/05-frontend/routing.md`.
- Leer `docs/01-architecture/frontend-backend-boundaries.md`.
- Leer `docs/06-design-system/principles.md`.

## Reglas

- Trabajar dentro de `apps/web`.
- Crear pagina dentro del grupo de ruta correcto.
- Usar componentes reutilizables cuando existan.
- Reflejar permisos de UI sin asumir seguridad.
- Mantener estados de carga, vacio, error y sin permiso.
