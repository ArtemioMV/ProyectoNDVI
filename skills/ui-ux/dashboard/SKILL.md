# Dashboard operativo

## Cuando usar
Construir paneles de trabajo (estado de parcelas, jobs, indices, alertas) orientados a decidir, no a impresionar.

## Documentacion de referencia
- `docs/06-design-system/principles.md`
- `docs/06-design-system/data-visualization.md`
- `docs/06-design-system/spacing.md`

## Reglas
- Priorizar informacion accionable y la comparacion (fechas, parcelas, indices, distribuciones, tendencias).
- Mostrar SIEMPRE calidad de escena, fecha y alcance de los datos; no ocultar cobertura ni nubosidad.
- Densidad util; evitar composicion de marketing y tarjetas anidadas.
- Estados de datos visibles: cargando, vacio, sin permiso.

## Checklist antes de terminar
- [ ] Cada widget responde a una decision, no a decoracion.
- [ ] Fecha/calidad/alcance de datos visibles.
- [ ] Comparaciones claras (periodo, parcela, indice).
- [ ] Sin tarjetas anidadas ni densidad de marketing.

## Anti-patrones
- Numeros grandes sin contexto de fecha/cobertura.
- Ocultar calidad de escena para que "se vea limpio".
