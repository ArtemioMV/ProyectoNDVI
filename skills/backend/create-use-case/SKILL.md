# Crear caso de uso

## Antes de modificar

- Leer el modulo backend relacionado.
- Leer `docs/08-security/tenancy.md`.

## Reglas

- Mantener el caso de uso libre de detalles HTTP.
- Recibir contexto autenticado y organizacion activa.
- Validar permiso y alcance antes de modificar datos.
- Agregar pruebas unitarias para reglas de negocio.
