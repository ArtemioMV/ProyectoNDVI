# Agregar permiso

## Antes de modificar

- Leer `docs/08-security/permissions.md`.
- Leer `docs/02-domain/identity-access.md`.

## Reglas

- Usar formato `recurso.accion`.
- Mantener clave estable y no dependiente del texto de UI.
- Definir alcance aplicable.
- Actualizar seed/catalogo cuando exista.
- Agregar pruebas de permitido, denegado y acceso fuera de alcance.
