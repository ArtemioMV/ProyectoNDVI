# Skills del proyecto

Estas skills son instrucciones reutilizables para agentes de desarrollo. No reemplazan la documentacion; apuntan a ella.

## Reglas

- Leer la documentacion indicada antes de modificar.
- Mantener cambios dentro de los archivos permitidos.
- No tocar modulos no relacionados.
- Agregar pruebas segun riesgo.
- Actualizar docs o ADR cuando cambie una decision.

Ver `docs/skills-installation.md` para descargar skills desde Git de forma controlada.
