# Geo Worker

Worker Python privado para trabajos geoespaciales.

## Responsabilidades

- Validar y procesar geometria.
- Consultar proveedores satelitales mediante adaptadores.
- Recortar raster por poligono.
- Calcular indices como NDVI.
- Generar estadisticas zonales.
- Guardar archivos en MinIO/S3.
- Reportar resultados a la API mediante endpoint interno firmado.
